Golden path: from zip to first answer

Forty minutes, together, step by step. At the end your team has a semantic view, an agent and an MCP server on TVM's own data, built with dbt, and the agent answers a first question in Snowflake CoWork. After that, everything is about making it good.

1 · Preflight check (everyone, during the kick-off)

  1. Snowsight, user menu (bottom left) » switch to your dev role.
  2. Download preflight.sql, open a new SQL worksheet and paste it in. Pick your dev warehouse and a database you work in (top right).
  3. Fill in the 3 lines at the top: your team number, and the database and schema of TVM's marts. Don't know the marts? Leave them as they are: the result lists the schemas you can read.
  4. Run all (Cmd/Ctrl + Shift + Enter).
  • Checks 1–8 are GREEN
  • Driver: rows 9 and 10 show the two files to paste (keep the worksheet open)

The three model files

Already in team_{{N}}/models/. Here for reference:

The semantic view: your business definitions.

{#- Team {{N}} semantic view (YAML, the same format Semantic Studio shows). Start small, build it, ask it, then grow.
    Fill in the 4 lines below (look at the table under Databases first), then build.
    Why the date and number column? A semantic view with only COUNT(*) is too thin:
    Cortex Analyst needs at least one dimension and one fact to write good SQL.          -#}
{%- set mart_table    = 'my_mart_table' -%}    {# a table listed in models/_marts_sources.yml #}
{%- set row_is        = 'TODO: what one row is, e.g. one subscriber per month' -%}
{%- set date_column   = 'my_date_column' -%}   {# e.g. month_start #}
{%- set amount_column = 'my_number_column' -%} {# e.g. mrr_eur #}

{{ config(materialized='semantic_view_yaml') }}
description: 'Team {{N}}: TODO your business question'
tables:
  - name: MART
    description: "{{ row_is }}"
    base_table: {{ base_table(source('tvm_marts', mart_table)) }}
    dimensions:
      - name: PERIOD
        synonyms: ['date', 'month']
        description: 'TODO: what the date means'
        expr: mart.{{ date_column }}
      # next: the columns people filter and group by, with business names, e.g.
      # - name: COUNTRY
      #   description: 'SE = Sweden, FI = Finland'
      #   expr: mart.country
    facts:
      - name: AMOUNT
        description: 'TODO: what the number is, unit and currency'
        expr: mart.{{ amount_column }}
    metrics:
      - name: ROW_COUNT
        description: 'Number of rows'
        expr: COUNT(*)
      - name: TOTAL_AMOUNT
        description: 'TODO: your first real KPI, e.g. total MRR in EUR'
        expr: SUM(mart.amount)

4 · Fill in four lines

At the top of sv_team_{{N}}.sql, point the skeleton at one mart table for your question:

LineWhat to putExample
mart_tableA table listed in _marts_sources.yml. Missing one? Add it there'fct_subscriber_months'
row_isWhat one row is, in business words'One subscriber per month'
date_columnThe main date column'month_start'
amount_columnOne number column you want to add up'mrr_eur'

Look at the columns under Databases in the left panel, or ask CoCo:

Look at the tables in models/_marts_sources.yml. Which one fits the question
"<your business question>"? Give me its main date column and one number column to sum.
Why a date and a number?A semantic view with only COUNT(*) is too thin. In our tests Cortex Analyst then sometimes wrote broken SQL. With one dimension and one fact it answered every time.

5 · Build

Open team_{{N}}/dbt_project.yml. The dbt controls are in the panel at the bottom of the editor: Profile · Environment · the command button with ▾.

  1. Profile: {{TARGET}}. Leave Environment on None.
  2. Click ▾ » Build » Execute. No flags, no Deps, no External Access Integration needed: the project has no packages.
  • Output ends with Done. PASS=3 and ERROR=0
Two run buttonsThe Run file ▾ button at the top only runs the open file. Use the bottom panel.

6 · Ask your first question

In a SQL file in your workspace:

SELECT * FROM SEMANTIC_VIEW({{DEV_DB}}.{{SCHEMA}}.SV_TEAM_{{N}}
  METRICS mart.total_amount DIMENSIONS mart.period)
ORDER BY 1 DESC LIMIT 12;

Then in Snowflake CoWork (ai.snowflake.com): pick Team {{N}} agent and ask something like "What was the total amount per month this year?"

  • The SQL returns numbers per month
  • The agent in CoWork answers with the same numbers
Agent missing in CoWork, or "not authorized"?CoWork uses your default role, and only that role sees your agent. Set your dev role as default (user menu » Settings), reload CoWork. Still missing? Call a facilitator: the agent may need adding to the account's CoWork list.

7 · Save a copy

Without Git, the workspace is the only copy. At every checkpoint (10:30, 12:15, 14:10): right-click team_{{N}} » Download, and drop the zip in the team channel.

Checkpoint 10:30Your team has one semantic view, one agent and one MCP server in {{SCHEMA}}, and the agent answers in CoWork. Now continue with 1 · Discover your data and make it answer your question.
